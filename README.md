
# ⚔️ RPG Console Game (Node.js)

Текстовая RPG-игра на Node.js с архитектурой MVC, системой боёв, прокачкой, лутом, картой и базовой поддержкой PvP (WebSocket концепт).

---

## 🚀 Стек технологий

- Node.js
- JavaScript (ES6)
- readline-sync (ввод в консоли)
- chalk (цветной вывод)
- fs (сохранения)
- ws (WebSocket для PvP)

🌐 Как работает PvP (WebSocket)

WebSocket — это постоянное соединение между клиентом и сервером.

🔁 Принцип:

1. Игрок подключается к серверу


2. Сервер держит соединение открытым


3. Игроки отправляют действия (атака, движение)


4. Сервер пересылает их всем подключённым игрокам



👉 Это позволяет сделать “живой” мультиплеер
