# ⚔️ Text-RPG: Dark Souls Edition (Node.js)

Текстовая ролевая игра в жанре roguelite с пошаговыми боями, системой прокачки, лутом и исследованием подземелий. Вдохновлена механиками D&D 5e и атмосферой Dark Souls.

---

## 🚀 Стек технологий

- Node.js (v18+)
- JavaScript (ES6)
- `readline-sync` – консольный ввод
- `chalk` – цветной вывод в терминал
- `fs` – локальное сохранение игр

---

## 🎮 Возможности (текущий MVP)

### ⚔️ Боевая система на базе D&D 5e
- Атака vs **Класс Брони (AC)** – уклонение, а не резист к урону
- Бросок d20 + модификатор силы + бонус мастерства
- **Критические удары** (естественная 20 на кубике) – удвоение костей урона
- **Промахи** – если бросок ниже AC цели
- Враги имеют фиксированный урон (кость + бонус)

### 🧠 Простые, но разнообразные монстры
- 5 видов врагов с разной редкостью появления (от 60% до 1%)
- Каждый монстр задаёт: HP, AC, урон, опыт и золото за убийство
- Никакого динамического генератора – баланс закладывается в данные

### 🎒 Diablo-подобный инвентарь
- Экипировка: шлем, броня, ботинки, кольца (до 3), оружие (до 2)
- **Рюкзак** для хранения неэкипированных предметов
- Предметы с атрибутами `attack` и `defense` влияют на модификатор атаки и AC
- Редкости: common / uncommon / rare (можно расширить)

### 💊 Лечение с кулдауном
- Один раз в 3 хода можно восстановить 20% максимального HP
- Игрок не может спамить хилы – нужно тактическое планирование

### 🗺 Исследование подземелья (события)
- **Бой** – столкновение со случайным монстром
- **Целебный колодец** – бесплатное лечение + небольшой опыт
- **Взлом замка** – мини-игра на последовательность 1/0 с ограниченными попытками

### 🎨 Улучшенный UI и управление
- Цветные сообщения (chalk): успех – зелёный, ошибка – красный, информация – синий
- **Горячие клавиши** в главном меню: `E` (исследовать), `S` (статистика), `I` (инвентарь), `G` (сохранить), `Q` (выход)
- Подтверждение выхода из игры
- Отображение шанса крита (5%) и бонуса атаки прямо в интерфейсе боя

### 💾 Сохранения
- Автоматическое сохранение при выходе через меню
- Ручное сохранение в любой момент (пункт 4/G)
- Загрузка прогресса при старте игры
- Файл `save.json` в корне проекта

## ▶️ Установка и запуск

### 1. Клонировать репозиторий
```bash
git clone https://github.com/your-username/text-rpg.git
cd text-rpg
```

### 2. Установить зависимости
```bash
npm install
```
### 3. Запустить игру
```bash
node app.js
```
При первом запуске будет предложено создать нового персонажа или загрузить сохранение (если есть save.json).
